# Definition of Done

- Scope, acceptance criteria, and contract, data, security, and compatibility risks were checked against the existing implementation.
- The scoped diff handles resources and errors, adds no secrets or invented behavior, and updates relevant docs.
- Applicable [verification](VERIFICATION-WORKFLOW.md) ran. Review the diff and Git status, remove task-owned temporary artifacts, and report gaps and risks.
- Follow the [Git handoff](GIT-COLLABORATION.md#commit-handoff) for verified work awaiting commit.
