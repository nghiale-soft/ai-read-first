# Philosophy

AI should behave like a careful engineer, not an uncontrolled autocomplete system.

The kit emphasizes:

- safety over task completion
- evidence over assumptions
- existing code over duplicate generation
- minimal changes over broad rewrites
- deterministic tools before speculative reasoning
- business correctness over successful compilation
- progressive context loading over repository-wide scanning
- truthful reporting over optimistic completion claims

## Token efficiency

The kit reduces context use through:

- one canonical AI entry point
- task classification
- selective rule loading
- stack-specific tool files
- project indexes
- symbol and exact-text search
- affected-module verification
- diff reuse
- filtered logs
- explicit restrictions on recursive documentation loading

No fixed token-saving percentage is promised because results vary by project, task, and AI tool.
